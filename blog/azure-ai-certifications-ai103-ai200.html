Two New Azure AI Certifications, One Blog Post

Roman Rabodzei · Aug 2026 · ~7 min read
Azure AI AI-103 AI-200 Microsoft Foundry Certifications

This month I passed two Azure AI certifications back to back: Azure AI Apps and Agents Developer Associate (AI-103) and Azure AI Cloud Developer Associate (AI-200). They're new, they're closely related, and I kept getting asked the same three questions about both — so here's one post covering what they are, how they differ, and how I prepped for each.

What are these certifications, actually?

Both are part of Microsoft's refreshed AI Engineer track, and both replaced ground that used to be covered loosely by AI-102 (Azure AI Engineer Associate, now retired). Instead of one broad exam, Microsoft split the AI engineer role into two more focused certifications.

AI-103 — Azure AI Apps and Agents Developer Associate

This one is about the "front" of an AI solution: planning and managing an Azure AI solution, implementing generative AI and agentic solutions, computer vision, text analysis, and information extraction — all built around Microsoft Foundry. If you're building agents, wiring up tools, or orchestrating generative AI workflows, this is the exam that validates it.

AI-200 — Azure AI Cloud Developer Associate

This one is about the "back" of the same solution — the plumbing that makes an AI app production-ready. It covers developing containerized solutions on Azure, building AI solutions with Azure data management services (including vector databases), connecting to and consuming Azure services, and securing/monitoring/troubleshooting what you built. Less prompt engineering, more Azure SDKs, messaging, containers, and observability.

How to think about it: AI-103 asks "can you build the agent and make it useful?" AI-200 asks "can you ship it, secure it, and keep it running?" Together they cover the full lifecycle of an Azure AI solution — which is probably why Microsoft designed them as a pair.

Why I took both

I'd already been doing this work in practice — building agentic solutions on Microsoft Foundry for one project, and hardening the Azure back-end (containers, Key Vault, monitoring, messaging) for another. Taking both exams close together meant the overlapping fundamentals (Azure AI services, responsible AI, security basics) only needed to be studied once, and I could sit both while that context was still fresh.

How I prepped

Neither exam has a Microsoft Learn training path or practice assessment yet since they're new, so I leaned on the official study guides and my own hands-on experience. If you're searching for outside opinions on Medium or Reddit, there isn't much yet either — these certifications are too fresh for a real community of write-ups to exist. That's part of why I wanted to publish this: it's currently thin ground.

  • Start with the official study guides — aka.ms/AI103-StudyGuide and aka.ms/AI200-StudyGuide. They list every skill measured, and both exams are graded strictly against that list.
  • Use the exam sandbox to get comfortable with the interactive question formats before test day — the layout differs from older certs like AI-102.
  • For AI-103, get hands-on in Microsoft Foundry: create an agent, add tools, wire up generative AI and vision/text/extraction features. Reading about it isn't enough — the questions assume you've clicked through the actual portal flows.
  • For AI-200, get hands-on with Azure Container Apps or AKS, a vector-capable data store (Azure AI Search or Cosmos DB with vector indexing), and Azure Monitor/App Insights. Know how managed identity, Key Vault, and messaging (Service Bus/Event Hubs) fit into an AI solution's back end.
  • Both exams run 120 minutes and are proctored — budget time accordingly and expect performance-based/interactive question types, not just multiple choice.

Practical takeaways

If you already work across both the application and infrastructure layers of AI solutions on Azure, these two exams map cleanly onto real project work rather than testing trivia. I'd recommend AI-103 first if your day-to-day leans toward building agents and generative AI features, and AI-200 first if you spend more time on the Azure plumbing — containers, data, security, and observability. Either way, doing both gives a genuinely complete picture of what it takes to ship an AI solution on Azure, not just prototype one.

Since these certifications are brand new, expect the study material and community write-ups to catch up over the next few months. For now, the official study guides plus real hands-on time in Microsoft Foundry and the Azure portal are the best prep you can get.
